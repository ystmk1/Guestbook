# Guestbook

ACT festival guestbook web — **SYMPOIESIS**

3중 링 위로 뻗은 가지 끝마다 방명록 한 줄이 맺힌다.
관람객이 노드에 마우스를 올리면 회전이 멈추고 그 문장이 확대되어 읽힌다.

---

## 지금 상태

**로컬 모드로 돈다.** 환경변수를 넣지 않으면 이 브라우저의 `localStorage` 에만
저장된다. 전시장 노트북 한 대로 운영하는 지금 방식에 맞다. 인터넷이 끊겨도 동작한다.

Supabase 를 나중에 붙이려면 [서버 모드로 전환](#서버-모드로-전환) 참고.
코드 수정 없이 환경변수 두 개만 넣으면 된다.

> ⚠️ **로컬 모드에서는 브라우저 데이터를 지우면 기록이 함께 사라진다.**
> 전시 기간에는 하루 한 번 `Ctrl+Shift+S` 로 백업 파일을 받아둘 것.

## 관람객이 하는 일

- 하단 카드에 문장을 쓰고 **Enter** — 문장이 자기 자리로 날아가 가지 끝에 맺힌다
- **Shift+Enter** 로 줄바꿈 (최대 3줄, 140자)
- 닉네임은 선택 — 안 쓰면 "익명"
- 노드에 **마우스를 올리면** 회전이 멈추고 그 문장이 확대된다
- 노드를 **클릭하면** 그 상태로 고정, 다시 클릭하면 해제

## 운영자 단축키

관람객에게는 아무 흔적도 보이지 않는다.

| 키 | 하는 일 |
| --- | --- |
| `Ctrl` + `Shift` + `S` | **전체 백업 내려받기** (JSON + CSV) |
| `Ctrl` + `Shift` + `O` | 백업 JSON 에서 복원 |
| `Ctrl` + `Shift` + `H` | 지금 **고정한** 기록 숨기기 (PIN 필요) |
| `Alt` + `F` | 전체화면 토글 |
| `Esc` | 열린 창 닫기 |

숨기려면 먼저 그 노드를 **클릭해서 고정**한 다음 `Ctrl+Shift+H`.
숨긴 글은 삭제되지 않고 격리 보관되어 백업 파일의 `quarantined` 에 남는다.

기본 PIN 은 `1234`. 바꾸려면 프로젝트 루트에 `.env` 를 만들고:

```
VITE_ADMIN_PIN=원하는PIN
```

## 부적절한 글 차단

로컬 모드에서는 [`src/lib/filter.ts`](src/lib/filter.ts) 가 거른다.

- 금칙어 (띄어쓰기·기호로 회피해도 잡는다: `시 발`, `시.발` → 동일 처리)
- 링크·연락처 스팸
- 같은 글자 8회 이상 반복

걸린 글은 **삭제하지 않고 조용히 격리**한다. 작성자 화면에는 정상 등록된 것처럼
보이고 화면에만 안 뜬다 — 막혔다는 반응을 주면 더 시도하기 때문이다.

금칙어를 추가하려면 `src/lib/filter.ts` 의 `WORDS` 배열에 넣고 다시 배포하면 된다.

## 전시장 노트북 세팅

1. `npm run build` → `dist/` 를 그대로 쓰거나, Vercel 배포 URL 을 연다
2. 브라우저를 열고 **전체화면**(`Alt+F` 또는 `F11`)
3. 노트북 절전 설정을 "안 함"으로 — 앱이 Wake Lock 을 걸지만 OS 설정이 우선이다
4. 마우스는 있어야 한다 (호버가 읽기의 핵심 동작)

**로컬 모드에서 주의할 점**

- 기록은 **그 브라우저의 그 주소**에 묶인다. `localhost` 로 쓰다가 Vercel URL 로
  바꾸면 이전 기록이 안 보인다 — 처음부터 한쪽으로 정하고 끝까지 그것만 쓸 것
- 시크릿 창에서 열면 창을 닫는 순간 전부 사라진다
- 브라우저 "인터넷 사용 기록 삭제"에 쿠키·사이트 데이터가 포함되면 같이 지워진다

## 서버 모드로 전환

여러 기기에서 동시에 쓰거나, 기록을 브라우저 밖에 두고 싶을 때.

1. Supabase 프로젝트를 만들고 **SQL Editor** 에 
   [`supabase/schema.sql`](supabase/schema.sql) 을 통째로 붙여넣고 RUN
   - 실행 전에 파일 6번 항목의 `'CHANGE-ME-1234'` 를 본인 PIN 으로 바꿀 것
2. **Project Settings → API** 에서 URL 과 `anon` 키를 복사
3. Vercel → Settings → Environment Variables 에 추가

   ```
   VITE_SUPABASE_URL=https://xxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
   ```

4. 재배포

전환하면 자동으로 붙는 것들:

- 여러 화면 간 **실시간 동기화**
- **서버측 필터** — 클라이언트를 뜯어고쳐도 우회 불가
- **도배 차단** — 같은 기기 10초 내 재작성 / 1시간 30건 상한
- **오프라인 큐** — 전송 실패한 글을 쌓아뒀다가 연결되면 자동 재전송
- 관리자 숨김 PIN 을 서버가 검증 (해시로 저장, 클라이언트에 노출 안 됨)

`anon` 키는 공개되어도 되는 키다. RLS 정책이 "숨겨지지 않은 글 읽기 + 글쓰기"만
허용하고 수정·삭제 정책은 아예 만들지 않았다.

## 구조

```
src/
  main.ts              배선
  config.ts            전시 중 만질 값 모음 (속도·개수·한도)
  scene/
    rng.ts             결정론적 난수 — 시드가 같으면 가지 모양도 같다
    structure.ts       3중 링 + 프랙탈 가지 (가지 끝 364개)
    pointcloud.ts      중앙 수조 스캔 목업
    world.ts           렌더 루프 · 호버 · 포커스 카메라
  ui/
    overlay.ts         3D 위 텍스트 층 (라벨 · 포커스 카드)
    composer.ts        입력부
    admin.ts           숨김 · 백업 · 복원
  lib/
    store.ts           저장소 (로컬 / 서버 양쪽)
    filter.ts          로컬 모드 필터
    supabase.ts        클라이언트
supabase/
  schema.sql           서버 모드용 전체 스키마
```

### 설계 메모

- **가지 끝은 364개.** 기록이 그보다 많아지면 오래된 자리부터 최근 글이 덮는다.
  화면에는 최근 364개가 보이고, 기록 자체는 최대 5000건까지 보관된다.
- **난수 시드를 바꾸지 말 것** (`structure.ts` 의 `77002`). 시드가 같으면 어느
  기기에서 열어도 가지 모양이 똑같다. 전시 기록 사진과 실물 화면이 어긋나지 않는다.
- **글자는 캔버스가 아니라 DOM 으로 그린다.** 한글 렌더링 품질 차이가 크다.
  대신 화면에 동시에 뜨는 라벨을 14개로 제한한다.
- **포커스는 카메라를 이동시키지 않는다.** 조준점과 `zoom` 만 바꾼다. 구조물
  안으로 날아 들어가 화면이 엉키는 일이 없고, 되돌아올 때 구도가 정확히 복원된다.
